五分鐘上手

First voyage

沒有 NovelAI 帳號也能先用示範模式試玩完整流程。

  1. 連上 NovelAI（可以先跳過）

    到 NovelAI 官網 → 帳號設定 → Get Persistent API Token，把 pst- 開頭的 Token 貼到「設定 → 連線」。沒有 Token 時會自動用示範模式，畫出抽象卡面讓你體驗流程，不花任何額度。

  2. 挑一個卡池

    「召喚」頁左邊是卡池清單。內建角色池、場景池，還有道具、裝飾邊框、文字標題、光效等透明素材池。也可以按 ＋ 自己開新的卡池。

  3. 按下召喚

    單抽或連抽（2～10 抽）。召喚時會有小魚躍入卡面、卡背由粒子聚合的演出，翻開就是剛畫好的新圖。

  4. 幫卡片取名、收進卡冊

    每張卡可以取中文名和英文稱號，也可以交給系統隨機取。抽到的卡先放在卡冊下方的「待收納」，拖進卡冊頁面就收好了。

  5. 到工坊加工

    把喜歡的卡做成會動的 LIVE 卡、3D 閃卡，加上燙金、特效、卡框，再匯出成影片、GIF 或可以轉動的網頁。

Danbooru 詞庫 4,889 個 TAG

NovelAI 是用 Danbooru 的標籤訓練的。詞庫收了真的存在、常用的 TAG，每個都有中文名，分成人物、頭髮、臉部、服裝、配件、動作、鏡頭、場景、光影、畫風、物品、食物、動植物 13 大類。點一下加入，再點一下拿掉。

隨機詞庫 每抽都不一樣

每條規則是「一個詞庫，每次抽幾個」，例如髮色抽 1 個、頭飾抽 0～2 個。可以只勾自己喜歡的幾個 TAG 來抽，同一個詞不會重複。只有抽中的詞會送出，不會浪費提示詞長度。

打字自動提示 中英都可以

在提示詞框打 twin 會跳出雙馬尾、雙麻花辮；直接打 貓 也會跳出 cat、cat ears。上下鍵選，Enter 確定。

🎲 隨機提示詞

像 NovelAI 的骰子，按一下就換成一組隨機的人物、服裝、姿勢、構圖和場景。按錯了可以復原。

智慧翻譯

用中文描述想要的畫面，例如「銀色長髮的精靈少女，穿著白色洋裝」，轉成 grey hair, long hair, elf, 1girl, white dress。填了自己的 AI 金鑰後，還能翻成英文或日文的自然語句。

完整 NovelAI 參數

  • 模型 V3～V5、尺寸、步數、引導、取樣器、種子
  • 多角色分開描述，可以指定站位
  • 圖生圖、Vibe 風格參考、角色參考
  • V5 透明背景，適合做道具和裝飾素材

提示詞旁有「預估長度」，NovelAI V4 以上的上限約 512 tokens，快超過時會變黃、變紅提醒你。

工坊

The atelier

把一張圖做成會動、會反光的收藏卡。

深度 3D AI 景深

在瀏覽器裡用 Depth Anything 分析遠近，滑鼠移動或手機傾斜時，人物和背景會前後錯開，有真的立體感。

LIVE 拆件 動態皮膚

把頭髮、胸口、眼睛、飾品塗成部件，設定飄動、呼吸、擺動、眨眼、漂浮、看向游標，讓角色像 Live2D 一樣動起來。

圖層 像 PSD

上傳的圖、素材卡、裝飾、卡背都能當圖層，分成最上層、外圍、主體、背景四組，可以移動、縮放、旋轉、裁切，最後合成成新卡片。

閃卡工藝 3D 全息卡

珍珠、銀箔、燙金、極光、玫瑰金等鐳射材質，滑鼠移上去卡片會轉動、流光。可以加卡框、卡名、稱號、編號與風味文字。

手感工藝 燙金・打凸・壓紋

燙金、燙銀、玫瑰金、古銅、黑燙、幻彩燙、打凸、壓紋、UV 亮油，可以加在任何圖層、卡框文字，或直接從原圖取範圍。例如把圖裡的金色飾品變成真的燙金，再配上亞麻、皮革、水彩紙紋。

做好的作品可以匯出成 WebM 影片、高清 GIF、PNG，閃卡還能匯出成一個可以轉動的網頁檔，傳給朋友用瀏覽器打開就能玩。也可以放到首頁輪播展示。

常見問題

Questions
要花錢嗎？

網站本身免費。生圖用的是你自己的 NovelAI 帳號：Opus 方案在 1024×1024 以內（含 832×1216）、步數 28 以下時不扣 Anlas，其他情況依 NovelAI 的規則計算。連抽前會先提醒你會送出幾次請求。

我的 Token 和卡片會被收集嗎？

不會。Token 只存在你自己的瀏覽器；線上版生成時會經過中繼原封不動轉給 NovelAI，中繼不保存、不記錄任何東西。卡片、圖片、卡冊都只存在你的瀏覽器。

換電腦或清除瀏覽器資料，卡片會不見嗎？

會，因為資料只存在這個瀏覽器。到「設定 → 資料」匯出備份檔，換電腦後再匯入就能完整搬過去。備份檔不會包含你的 Token 和金鑰。

召喚失敗會扣保底嗎？

不會。任何一抽失敗會立刻停下、不自動重試，失敗那一抽也不計入抽數與保底。

提示詞裡的 <紅髮|藍髮> 是什麼？

舊式的隨機寫法：召喚前就在你的瀏覽器裡挑好其中一個，NovelAI 只會收到挑中的詞。現在建議改用「③ 隨機詞庫」，可以一鍵轉換，比較好管理。

沒有 NovelAI 帳號可以玩嗎？

可以用示範模式體驗召喚、卡冊、工坊的所有流程，卡面會是程式畫的抽象圖。工坊也可以上傳你自己的圖片來加工。
